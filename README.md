# Jogo de Adivinhação em C

Projeto desenvolvido com a linguagem C para praticar lógica de programação, estruturas de decisão, laços de repetição e geração de números aleatórios.

## Funcionalidades

- Menu principal
- Sistema de regras
- Três níveis de dificuldade
- Número aleatório gerado automaticamente
- Limite de 10 tentativas
- Dicas de "Muito alto" e "Muito baixo"
- Opção de jogar novamente
- Validação das opções dos menus

## Dificuldades

- Fácil: números de 1 a 15
- Médio: números de 1 a 50
- Difícil: números de 1 a 100

## Observações

- O programa aceita apenas números inteiros.
- Não há tratamento para entrada de letras.
- Não há tratamento para números decimais.

## Conceitos praticados

- Variáveis
- Operadores lógicos
- Estruturas condicionais
- Estrutura switch
- Laços de repetição
- Biblioteca stdlib.h
- Biblioteca time.h
- rand()
- srand()
